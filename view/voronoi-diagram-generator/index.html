A Voronoi diagram partitions a plane into regions close to each of a given set of seed points. For each seed point, there is a corresponding region consisting of all points closer to that seed point than to any other.

Click anywhere on the canvas to add a new seed point, dynamically reshaping the cellular pattern in real-time.
