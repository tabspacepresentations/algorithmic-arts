A Julia set consists of values for which the iterative function f(z) = z² + c remains bounded, forming complex fractal boundaries in the complex plane.

By varying the constant complex parameter c and coloring points based on escape-time velocity, infinitely intricate and mesmerizing self-similar structures emerge.
